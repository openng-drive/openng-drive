1.6.123 Oct 2026
Latest

Plain BeamNG when you don't use the launcher.

  • Since 1.5.2 the openNG pause menu also appeared when BeamNG.drive was started from Steam. Now openNG only shows up in games started with openNG.drive. Start the game any other way and it is untouched BeamNG
  • In a game started with the launcher, the menu still comes back after BeamMP joins a server or the game reloads its scripts
1.6.023 Oct 2026

Everything checked, lots fixed.

This update doesn't add features. The whole launcher was gone through file by file and the bugs found were fixed.

  • Pause menu: two quick clicks no longer lose the first one, the Patreon, PayPal and Discord buttons open their pages again, the weather buttons in the separate pause window work, and the temperature (low, average, high) always stays in order
  • The game is no longer left paused when a game screen can't be opened, and the big map closes back to driving reliably
  • The loading screen no longer covers the BeamMP server list, and it closes when the game quits
  • Your BeamNG settings, the mod list and the launcher settings are now written safely: a damaged file is kept instead of being replaced by empty defaults
  • Mods: installing keeps the old version until the new one is in place, broken downloads are cleaned up, and deleting can't reach outside the mods folder
  • The self-updater checks the download more strictly and can't install twice at the same time
  • Web pages in your browser can no longer send commands to the launcher in the background
  • Server hosting: no double start, stopping during a download works, router port forwarding is cleaned up properly
  • Folder paths with umlauts or Cyrillic letters work in the folder picker
  • About 140 missing English, French and Russian translations added, and small layout fixes for small windows
1.5.223 Oct 2026

The pause menu stays.

  • Sometimes Esc opened BeamNG's own menu instead of openNG's. That happened when the game reloaded its scripts (BeamMP does this when it joins a server), when it was started from Steam instead of the launcher, or after leaving photo mode, the map or the vehicle configuration in certain ways
  • The game now loads the openNG menu by itself every time its scripts start, and the menu notices when you're back on the road even if a game screen didn't report that it closed
  • The pause menu also works while the launcher is closed
1.5.119 Oct 2026

Drop-down lists work in the game.

  • The lists in the pause menu settings (quality levels, anti-aliasing, resolution, VR and others) didn't open, because BeamNG's in-game browser can't show the normal Windows lists. They are now openNG's own lists and open like everywhere else in the launcher
  • Choosing an overall quality preset shows the new detail levels straight away
1.5.019 Oct 2026

More of BeamNG 0.40 in the pause menu.

  • "Customise vehicle" replaces the old tuning button. It opens BeamNG's vehicle configuration straight on the tab you pick: parts, tuning, paint & design, occupants or options. Saving a config and adjusting the mirrors are one click away too
  • Weather & time has the new temperature from 0.40: set the average, the daily low and the daily high, and see the curve over the day with the current time marked
  • Split screen: set up local multiplayer with gamepads or wheels from the pause menu, and end it from there too
  • New Screen tab in the pause menu settings: display mode, resolution, refresh rate and monitor (applied with one click), plus brightness, HDR and frame rate limits
  • New VR tab: switch VR on or off, centre the view, and set the resolution in the headset, comfort options, controllers and how menus show up in VR
  • Launcher settings: the new 0.40 graphics options (light sources, decals, extra detail when zooming, motion blur on your own car, distant shadows, HDR interface brightness) and a VR card with "switch VR on when the game starts"
  • The radial menu (E) has a new look: black, no glow and no orange, with clean white highlights
1.4.119 Oct 2026

The pause menu is back in 0.40.

  • When BeamNG.drive starts for the first time after an update, 0.40 now tidies up its user folder and moves away every file it doesn't know. That took the openNG pause menu with it, so Esc opened the game's own menu. The launcher now keeps its files in a place the game leaves alone, and puts the menu back if the game moves it anyway
  • The rain sound and the loading screen survive game updates the same way
1.4.019 Oct 2026

Ready for BeamNG.drive 0.40.

  • BeamNG 0.40 has DLSS, FSR 3, FSR 4 and XeSS built in. The launcher now uses those directly, with resolution scaling (Quality, Balanced, Performance …) and sharpness. ReShade isn't needed for DLSS any more
  • Options your graphics card can't run are greyed out, for example DLSS without an NVIDIA RTX card
  • New in the in-game pause menu: anti-aliasing, resolution scaling, sharpness, reflections, mirrors and screen space reflections under Settings, Graphics
  • Fixed for 0.40: the game version shows up again, reflections and mirrors use the new quality levels (the old switches did nothing in 0.40), and performance mode knows the new settings

1.3.119 Oct 2026

English by default, and a new home for downloads.
